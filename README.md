# LoveCheck - Couple Compatibility Game

A viral, fun, and aesthetic game for couples to check their compatibility.

## 🎮 How to Play

1.  **Start a Game**: Enter your name, your partner's name, and pick a question category (Romantic, Funny, Deep).
2.  **Answer Questions**: Answer 10 questions about your relationship honestly.
3.  **Share the Link**: Send the unique game link to your partner.
4.  **Partner Answers**: Your partner answers the same questions.
5.  **See Results**: Once both are done, the app reveals your compatibility score and analysis!

## 🛠 Tech Stack

- **Frontend**: Svelte 5 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Svelte Transitions + CSS Gradients
- **Backend**: None! Game state is encoded in the URL for instant sharing and zero server costs.

## 🚀 Development

```bash
npm install
npm run dev
```

## 📦 Deployment

Build for production:

```bash
npm run build
```

You can deploy the `dist` folder to any static host (Vercel, Netlify, GitHub Pages).
